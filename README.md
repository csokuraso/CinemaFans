# CinemaFansWinForms

WinForms-застосунок C#/.NET для підтримки поціновувачів кінематографу.

## Вхід
- admin / admin123 — адміністратор
- user / user123 — звичайний користувач

## Функції
- перегляд фільмів;
- пошук за назвою, режисером, акторами або жанром;
- додавання фільмів адміністратором;
- додавання відгуків і оцінок користувачами;
- автоматичний розрахунок середньої оцінки;
- рейтинг найкращих фільмів за жанром або загалом.

## Запуск
Відкрити `CinemaFansWinForms.sln` у Visual Studio 2022 або виконати:

```bash
dotnet run --project CinemaFans.App
```
